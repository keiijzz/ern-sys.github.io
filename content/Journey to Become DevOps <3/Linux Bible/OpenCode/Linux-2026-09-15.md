# Symbolic LInk (Soft Link)   "Shortcut"
Symbolic Link = Shortcut ala Windows. File yang nunjuk ke file lain.
## Bikin:
`ln -s /home/netemplar/Git/ern-sys.github.io/content/Journey to Become DevOps <3/Shortcut`

| Contoh Praktek                | Command                                  |                |
| ----------------------------- | ---------------------------------------- | -------------- |
| `ln -s` = bikin simbolic link | `echo "File ini asli" > ~/file-asli.txt` |                |
| bikin shortcut                | `ln -s ~/file-asli.txt ~/shortcut.txt`   |                |
| cek nya                       | `ls -la ~/                               | grep shortcut` |

**Yang perlu lo tau adalah:
`ln -s` = bikin Symbolic link, kalau file nya di hapus > shortcut juga jadi broken (Rusak, nunjuk ke mana-mana). link itu cuma "penunjuk Alamat asli". LInk bisa nunjuk Lintas Filesytem (Beda Hardisk)**

# STUDY CASE:
Config `/etc/localtime -> /usr/share/zoneinfo/Asia/Jakarta`. Kalau lo ganti zonas waktu tinggal ubak symlink-nya, gak perlu copy file.

# HARDISK LINK - "DOBEL ALIAS"
Hardisk link = File yang "senyawa" dengan file Lain. Dua nama, satu isi, satu data.
