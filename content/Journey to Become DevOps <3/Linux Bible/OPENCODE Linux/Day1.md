`whereis` = (Pencari Executable di $PATH + Source Code + Man Page): kenapa hasil whereis lebih panjang, karena dia perintah / command yang mencari 3 hal sekaligus, yakni pencari executable berada, source code nya di dir mana, serta man page nya sekaligus. 
`which` = Pencari Executable di $PATH.

`CTRL + R` -> lalu ketik kalimat apa yang mau di cari. itu akan nyari command yang kamu ketikan terakhir kali dan tanpa mengetik ulang.
`man ls`
`man` dalam linux, ada reference untuk mengetahui semua command dengan deskripsi nya menggunakan perintah ini.  lalu kamu bisa memulai pencarian dengan kata yang kamu cari menggunakan `/` dan masukan kata yang ingin kamu cari.
`man -k` - ketika lu lupa perintah apa untuk membuat sesuatu, misalkan lu lupa cara nya compress sesuatu file dengan `command` apa. nah ini kegunaan `man -k` berada. lu bisa ketik `man -k compress` dan disana akan muncul semua command yang mengandung fungsi dan kata `compress` atau lu bisa pake `man -k list directory` nah lu fdisana akan nemuin semua nya.
