`pwd` = where we in directory
`ls -la` = `ls` berarti listing folder -- `-la` berarti list all
`/` -- folder root
`/etc/` berarti file config folder di dalam linux
`/var/log/` adalah tempat semua aplikasi buang log nya disini atau catatan error nya disini. 
`/proc` adalah folder gaib (seperti memory atau proccess)

`ls -lh` berarti listing dengan fungsi `-lh` list humanreadable
# Senjata Utama Day 1 - Day 3
`cat, less, head, tail, grep, pipa ( | )` 

### CAT
menampilkan isi file semua (disarankan file cuma berisi 30 baris)
`cat scrapt.py`

## LESS
digunakan untuk melihat isi file per paper. seperti membaca PDF
`less`/var/log 
(ketik `/` diikuti kata yang mau di cari lalu enter)
(ketik `n` untuk cari kata berikutnya)

## HEAD
`head /etc/passwd berarti melihat folder dari atas dengan 10-15 baris. 
`head -5 /etc/passwd` berarti menampilkan isi file dari atas sampai 5 baris ke bawah doang.

## TAIL
membaca isi file dari mulai bawah ke atas.
`tail -f /var/log/boot.log` 

## GREP & PIPA SAKTI ( | )
`ps aux | grep dropbox` berarti mengintip atau mencari services yang berjalan dengan memfilter hanya dropbox saja.
