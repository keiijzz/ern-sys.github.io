### 🧪 LAB DAY 1: "Kenalan Sama Rumahnya Linux" (Waktu: 30 Menit)

Buka terminal di ThinkPad T460s lu. Jalankan 3 langkah ini satu per satu dan perhatikan penjelasannya:

#### 1. Navigasi Dasar & Bedah Flag Command
Jangan cuma ketik `ls`. Ketik ini:
```bash
pwd
ls -la
```
* **Bedah Perintah:**
  * `pwd` (*Print Working Directory*): Menjawab pertanyaan *"Gue lagi berdiri di folder mana sekarang?"*.
  * `ls` (*List*): Nampilin isi folder.
  * `-l` (*Long listing format*): Nampilin detail permission, owner, ukuran file, dan tanggal modifikasi.
  * `-a` (*All*): Nampilin file tersembunyi (file yang diawali titik `.`, kayak `.bashrc` atau `.git`).

#### 2. Kunjungi 3 Folder Paling Sakral di Dunia DevOps
Di Windows lu kenal `C:\Program Files` atau `C:\Windows`. Di Linux semuanya berawal dari root `/`. Pindah ke root dan intip isinya:
```bash
cd /
ls -la
```
Perhatikan 3 folder ini (ini tempat hidupnya anak DevOps):
1. `/etc` → **Tempat file konfigurasi sistem.** (Contoh: config Nginx, config network, SSH, dll semuanya file text di sini).
2. `/var/log` → **Tempat semua aplikasi buang catatan/log error.** Kalau ada server down, folder ini yang pertama kali dibuka.
3. `/proc` → **Folder gaib (virtual filesystem).** Ini bukan file beneran di harddisk, tapi isi kepala (memory & process) Kernel Linux saat itu.

#### 3. Tes Eksplorasi Mandiri
Coba ketik ini di terminal lu:
```bash
cd /var/log
ls -lh
```
*(Flag `-h` artinya Human-readable, nampilin ukuran file dalam KB/MB/GB, bukan byte mentah).*
