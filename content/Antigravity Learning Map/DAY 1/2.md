### 🧪 LAB DAY 2: Inspeksi File & Log Kayak Senior (Waktu: 30 Menit)

**Skenario Nyata DevOps:**  
Server production lagi lemot atau crash. Lu cuma bisa masuk lewat SSH hitam-putih. Gak ada mouse, gak ada Notepad/VSCode buat buka file. Lu harus bisa bedah file config dan cari baris error di antara ribuan baris log dalam hitungan detik.

Di lab ini, kita bedah senjata utama: `cat`, `less`, `head`, `tail`, `grep`, dan pipa sakti `|` (Pipe).

---

#### 1. Baca File Tanpa Bikin Terminal Lu Penuh Muntahan Teks

Coba baca file identitas OS Linux laptop lu:
```bash
cat /etc/os-release
```
* **Kapan pake `cat`?** Kalau filenya pendek (di bawah 30 baris). `cat` bakal langsung nyemburin semua isi file ke layar.

Sekarang coba buka file yang isinya panjang:
```bash
less /etc/passwd
```
* **Bedah `less` (Wajib Lu Kuasai):**
  * `less` nampilin file per halaman (interactive pager).
  * **Navigasi:** Pake panah atas/bawah buat scroll.
  * **Pencarian Cepat:** Ketik `/` diikuti kata yang dicari (misal: `/edriel`), lalu tekan `Enter`. Tekan `n` buat cari kata berikutnya.
  * **Keluar:** Tekan tombol **`q`** (*Quit*) di keyboard.

---

#### 2. Intip Awal vs Akhir File (`head` & `tail`)

Seringkali lu cuma mau liat 5 baris pertama atau 10 baris terakhir dari sebuah log.
```bash
head -n 5 /etc/passwd
tail -n 5 /etc/passwd
```
* `-n 5` artinya batasi cuma tampilkan 5 baris (*Number of lines*).

**Senjata Paling Sering Dipake Anak DevOps:**
```bash
tail -f /var/log/boot.log
```
*(Kalau gak ada `boot.log`, bisa coba file log apa saja yang ada di `/var/log/`)*
* Flag **`-f`** (*Follow*): Terminal bakal "standby" mantau file log secara live. Tiap ada baris baru masuk, otomatis muncul di layar.
* *Cara keluar:* Tekan `Ctrl + C`.

---

#### 3. Filter Text dengan `grep` & The Magic Pipe (`|`)

Di Linux, lambang garis lurus tegak `|` (Pipe) artinya: **"Ambil hasil output dari perintah sebelah kiri, lalu lempar langsung jadi bahan input buat perintah sebelah kanan."**

Jalankan perintah ini:
```bash
cat /etc/passwd | grep edriel
```
* **Bedah Perintah:**
  1. `cat /etc/passwd` nampilin semua daftar akun user di sistem.
  2. Hasilnya gak dilempar ke layar dulu, tapi disaring lewat `| grep edriel`.
  3. `grep` cuma nampilin baris yang ada kata `edriel`-nya.

Coba lagi dengan filter non-case-sensitive (`-i` / ignore case):
```bash
ls -la /var/log | grep -i log
```
