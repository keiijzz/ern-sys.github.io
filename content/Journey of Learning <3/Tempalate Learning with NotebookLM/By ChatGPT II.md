# Workflow yang Paling Waras Buat Lo

## 1. Satu Workspace = Satu Skill

Contoh:

- Workspace MTCNA
    
- Workspace Linux
    
- Workspace Docker
    
- Workspace RHCSA
    

JANGAN dicampur.

Karena nanti AI:

- bingung dependency,
    
- roadmap bercampur,
    
- praktik jadi lompat-lompat.
    

---

# 2. Satu Core Material

Misalnya:

- 1 ebook/course utama MTCNA
    
- - official docs
        

Udah.

AI nanti:

- breakdown,
    
- roadmap,
    
- praktik,
    
- challenge,
    
- troubleshooting.
    

---

# 3. Fokus Tamat, Bukan Luas

Ini penting banget.

Skill technical itu:

> depth > breadth.

Orang yang:

- benar-benar ngerti subnetting,
    
- ngerti firewall,
    
- ngerti routing,
    
- ngerti troubleshooting,
    

akan jauh lebih berbahaya dibanding:

> “udah nonton 80 course.”

---

# 4. Gunakan AI Sebagai “Senior Engineer”

Bukan search engine.

Kalau belajar:  
jangan cuma bilang:

```txt
jelaskan NAT

Simulasikan saya sebagai network engineer junior yang harus mengkonfigurasi NAT di kantor kecil.

Ajarkan:
- cara berpikir,
- desain,
- implementasi,
- troubleshooting,
- dan kesalahan umum.
```

NAH.
