Haha itu karena **prompt lo terlalu panjang** — NotebookLM ada batas karakter di input chat-nya bro.

Solusinya gampang, ada 2 cara:

---

**Cara 1 — Pakai fitur "Save to note" (paling recommended)**

1. Paste prompt lo ke **Add note** di panel kanan (Studio)
2. Simpan sebagai note
3. NotebookLM akan otomatis baca itu sebagai konteks
4. Di chat tinggal ketik: _"Ikuti instruksi dari note yang sudah saya simpan, dan mulai dari sana"_

---

**Cara 2 — Pecah jadi 2 pesan**

1. Kirim bagian pertama prompt dulu, tunggu response
2. Lanjut kirim bagian kedua dengan awalan: _"Lanjutan instruksi sebelumnya:"_

---

Gue **recommend Cara 1** karena note itu permanen — jadi setiap sesi baru NotebookLM udah punya konteks instruksi lo tanpa perlu paste ulang.
